# モックを一般公開する手順

Claudeのアーティファクト（claude.ai のリンク）を使わずに公開する方法。用途に応じて選んでください。

---

## 方法A: GitHub Pages（このリポジトリから公開・推奨）

準備は済んでいます（`docs/` 配下に公開用ファイル、`.github/workflows/pages.yml` に自動デプロイ設定）。
GitHub側で有効化するだけで公開されます。

### 手順

1. GitHubで `emcyrup/freewan` → **Settings → Pages** を開く
2. **Source** を「**GitHub Actions**」に変更（「Deploy from a branch」ではない）
3. 数分待つと以下のURLで公開されます

```
https://emcyrup.github.io/freewan/                     ← トップ（資料一覧）
https://emcyrup.github.io/freewan/osaka-kitaku/mock/   ← 画面モック
```

以降は `main` ブランチに変更をpushするたびに自動で最新版が公開されます。

### 注意事項

- **このリポジトリは現在プライベートです。** 無料プラン（GitHub Free）では
  プライベートリポジトリのPages公開ができません。次のどちらかが必要です。
  - リポジトリを**パブリックに変更**する（Settings → General → 最下部 Danger Zone → Change visibility）
  - **GitHub Pro 以上**にアップグレードする（プライベートのまま公開可）
- 公開すると**URLを知っている人は誰でも閲覧できます**（`noindex` により検索結果には出ませんが、アクセス制限ではありません）。
- リポジトリをパブリックにする場合、リポジトリ内の全ファイルが公開対象になります。
  現時点の内容は要件定義書・導入プロセス・モック（サンプルデータのみ）で、実在の顧客情報は含まれていません。

---

## 方法B: Netlify Drop（アカウント不要・最短）

モックは1枚の自己完結HTMLなので、ドラッグ＆ドロップだけで公開できます。

1. `docs/osaka-kitaku/mock/index.html` をPCにダウンロード
2. https://app.netlify.com/drop を開く
3. ファイルをブラウザにドラッグ＆ドロップ
4. 即座に `https://xxxx-xxxx.netlify.app` のURLが発行される

- アカウント登録なしでも公開できます（ただし無登録の場合は一定時間で消えます。
  無料アカウントを作れば恒久的に残り、独自のサブドメイン名も設定できます）
- 更新するたびに手動で再アップロードが必要です

---

## 方法C: 社内・店舗内だけで見る（公開しない）

- `docs/osaka-kitaku/mock/index.html` をそのままメール等で送り、
  受け取った側がブラウザで開くだけで動作します（インターネット接続も不要）。
- 外部に一切出したくない場合はこの方法が最も安全です。

---

## どれを選ぶか

| | 常時最新 | 手軽さ | 費用 | 向いている場面 |
|---|---|---|---|---|
| A. GitHub Pages | ◎ 自動 | △ 初回設定あり | 無料（要パブリック化 or Pro） | 継続的に共有・更新する |
| B. Netlify Drop | △ 手動 | ◎ 数十秒 | 無料 | 7/30の商談で今すぐ見せる |
| C. ファイル配布 | × | ○ | 無料 | 外部に出したくない |

7/30の訪問で見せるだけなら**方法B**、導入検討が進んで継続的に共有するなら**方法A**をおすすめします。
